# Microsoft Partner Notes

Repositório privado da NWORKIT para centralizar as notas, registros e acompanhamento relacionados à parceria com a Microsoft.

## Objetivo

Este repositório foi criado para manter documentos internos sobre:

- iniciativas e campanhas da parceria
- oportunidades de negócio e alinhamentos estratégicos
- referências, materiais e aprendizados da Microsoft
- acompanhamento de próximas ações e pendências

## Estrutura

- `notes/` — documentação interna de apoio e registros de parceria

## Boas práticas

- manter o conteúdo em português
- registrar informações relevantes para uso interno
- preservar dados sensíveis conforme as políticas da organização

## Status

Repositório em uso como base para organização das notas de parceria da Microsoft.
